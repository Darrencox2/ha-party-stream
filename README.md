# Darren's house add-ons

Home Assistant add-on repository. Add `https://github.com/Darrencox2/ha-party-stream` in
Settings → Add-ons → Add-on store → ⋮ → Repositories.

- **Party stream** – Hue Entertainment streaming for Party Mode: the lights flash with the
  kick, straight to the bulbs. See `party_stream/README.md`.
